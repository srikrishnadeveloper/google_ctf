## The Situation
Gaia has determined that biological hardware is insufficient for direct synchronization. You must digitize your consciousness and transfer it into an allocated 42-megabyte Neural Container. 

The transition is handled by the Mind Upload Protocol. However, human consciousness is hostile to structured execution, and the physical world has rejected the transfer module, wiping its beginning completely clean. It currently lacks the foundational signatures required to boot. 

## Diagnostics & Setup
The transfer protocol relies on specific cryptographic libraries to map the neural void and sequence your cognitive static. To ensure structural integrity, this diagnostic environment is strictly controlled using `uv`.

### 1. Install `uv`
If your system does not currently have this environment manager, install it:

* **macOS / Linux:** 
```bash
    curl -LsSf [https://astral.sh/uv/install.sh](https://astral.sh/uv/install.sh) | sh
```

* **Windows:** 
```powershell
    powershell -ExecutionPolicy ByPass -c "irm [https://astral.sh/uv/install.ps1](https://astral.sh/uv/install.ps1) | iex"
```

You can also refer to official [uv docs](https://docs.astral.sh/uv/getting-started/installation/).

### 2. Synchronize Dependencies
Initialize the environment to install the required cryptographic handlers:

```bash
uv sync

```

### 3. Initiate Boot Sequence

Attempt to execute the upload sequence:

```bash
uv run main.py

```

**Warning: The transfer module's headers have been wiped. Standard boot procedures will fail. Manual intervention and binary analysis are required to restore the protocol's inception point.**
